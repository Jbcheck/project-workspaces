# JetBrains IDE Project Templates

## Usage

1. Create a new project in your JetBrains IDE
2. Configure the settings as needed
3. Copy the relevant configuration files from the `.idea` directory to this repository
4. Share with your team

## Important Settings

### Project Opening Behavior

To ensure projects don't interfere with each other:

1. Go to Settings > System Settings > Project Opening
2. Select "Open project in new window"

### Project Structure

Configure your project structure to only include relevant directories:

1. Go to File > Project Structure
2. Under Project Settings > Modules, ensure only relevant content roots are included
3. Remove any external directories that might cause the IDE to access unrelated projects
